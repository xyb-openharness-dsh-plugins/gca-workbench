## 四、撞形风险与处置

- **GcaPal 与同族仓品牌名撞形**：品牌占位名晨审追认时更换（DEV-PLAN §五#3）。
- **「化验」页面与 takayasu 仓撞形**：页面结构可同形，指标语境与解读口径不同（GCA 颅动脉随访语境）；指标目录在 CLINICAL-DATA.md 单列，不引用 takayasu 仓文档。
- **发作—缓解区间带与肝胆家族发作带同构**：区间带是家族通用组件，症状集（头痛/头皮压痛/下颌跛行/肢体跛行/PMR 晨僵）与视力预警为 GCA 专有。
