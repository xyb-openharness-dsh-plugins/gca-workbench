# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：巨细胞动脉炎（GCA）患者及家属照护者；含伴风湿性多肌痛（PMR）共病、长期激素减量随访中的 50 岁以上成人患者；患者组织志愿者协作使用

场景：确诊依据档案（颞动脉活检/影像/化验与症状描述）与误诊经历留痕；ESR/CRP 化验周期记录（按方法与机构可比组分列）；激素剂量阶梯（mg/d 按日期）与减量经历；头痛/头皮压痛/下颌跛行等发作—缓解区间；视力预警症状（新发视物模糊等，仅记录与就医提醒）；颞动脉超声/CTA/MRA 影像复查节奏与结果；PMR 共病随访条目；医生用药原文留档；复诊准备材料整理（默认私密）

核心流程：
1. 选择本机资料目录并导入化验/影像/报告
2. 核对候选信息，建立确诊依据档案与随访节律
3. 记录化验结果、激素剂量阶梯与发作—缓解经历
4. 整理影像复查节奏与医生用药原文
5. 生成复诊准备材料

完成结果：得到来源可追溯、可核对的个人病程档案：确诊依据、化验趋势与可比组、激素剂量阶梯与发作—缓解时间线、影像复查节奏与结果、视力预警症状与就医经历、用药记录、复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
