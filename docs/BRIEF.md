# 需求起点 · gca-workbench（巨细胞动脉炎 GCA）

版本 v0.1 · 2026-11-14 · 自动签认状态：初始化配置草案，晨审未追认。

来源：认领配置（issue #77）+ 家族脚手架初始化。用户、场景和流程是有效的 SPEC 互动素材；继承会话中已有明确确认的保留，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：巨细胞动脉炎（GCA）患者及家属照护者；50 岁以上发病人群为主，含合并风湿性多肌痛（PMR）的共病患者、激素阶梯减量期与视力预警高风险随访中的成人患者；患者组织志愿者协作使用。

场景：确诊依据档案（颞动脉超声晕轮征/颞动脉活检/CTA/MRA/PET-CT 与化验）与误诊经历留痕；ESR/CRP 化验周期记录（按方法与机构可比组分列）；激素剂量阶梯（泼尼松 mg/d 按日期记段）与托珠单抗等医生用药原文留档；发作—缓解区间（头痛/头皮压痛/下颌跛行/肢体跛行/PMR 晨僵）；视力预警症状（新发视物模糊/黑朦/复视→当日就医提醒占位，仅记录不判读）；影像复查节奏与结果；共病 PMR 以「医生已安排的随访」呈现；复诊准备材料整理（默认私密）。

核心流程：
1. 选择本机资料目录并导入化验/影像/活检报告
2. 核对候选信息，建立确诊依据档案与随访节律
3. 记录化验结果、剂量阶梯、发作—缓解经历与症状变化
4. 整理影像复查节奏与医生用药原文
5. 生成复诊准备材料

完成结果：得到来源可追溯、可核对的个人病程档案：确诊依据、ESR/CRP 趋势与可比组、剂量阶梯表、发作—缓解时间线、视力预警记录、影像复查节奏与结果、共病 PMR 随访条目、复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议。

初始布局选择：business-first。
