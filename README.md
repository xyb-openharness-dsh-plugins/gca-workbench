# 小脉宝 GcaPal 巨细胞动脉炎（GCA）工作台（品牌占位）

版本 0.1.0 · 2026-11-14 · 状态：M0 文档阶段（品牌名占位，晨审追认）。

本机优先的 GCA 确诊档案、ESR/CRP 化验随访、激素剂量阶梯、发作—缓解与视力预警记录、影像复查、共病 PMR 随访、复诊材料准备工作台。目标：50 岁以上 GCA 患者本人与家属照护者。

**诚实声明：0 患者访谈、0 临床审核**（如实标注）；所有医学阈值【待核】，判读归医生；演示数据为合成示例，未连接宿主。本工作台只做信息整理与就诊准备，不做诊断、不判活动度、不选治疗。

## 疾病概要

巨细胞动脉炎（GCA，Giant Cell Arteritis）是 50 岁以上发病的大/中血管肉芽肿性血管炎，颅动脉（颞动脉）受累为主；收录于《86 个罕见病病种诊疗指南（2025 年版）》（目录序号 #35【待核】）。工作台围绕四类患者关心的事组织：**化验趋势**（ESR/CRP，不同方法/机构不合并）、**剂量阶梯与发作—缓解**（泼尼松 mg/d 按日期记段；一次发作一个折叠单元）、**视力预警与影像复查**（新发视物模糊/黑朦/复视→当日就医提醒占位；颞动脉超声/CTA/MRA/PET-CT）、**症状与共病 PMR**（患者语言原文记录，PMR 以医生已安排的随访呈现）。点顶栏「?」看疾病概要四段（每段带来源行），详见 `docs/DISEASE-PRIMER.md`。

### 定义

巨细胞动脉炎（GCA，Giant Cell Arteritis）是 50 岁以上发病的大/中血管肉芽肿性血管炎，颅动脉（颞动脉）受累为主；收录于罕见病目录（序号 35【待核】）。本台面向已确诊 GCA 的成人患者本人，家属照护者可选用同一套记录；化验按每张单据自带的方法/单位/机构分组，不合并、不连线、不做差。

### 医学资料规范和指南情况

本台把可公开点开的指南页 / 期刊全文页与「未取得原件」分开标注；不写页码、不复制条文，也不把栏目页冒充原件。链接逐条验活脚本尚未跑，标注「待验活」。

### 目前治疗全景概要

随访与监测（ESR/CRP/血常规、激素期间 ALT/空腹血糖/血压）、影像复查（颞动脉超声晕轮征、CTA/MRA/PET-CT、颞动脉活检）与共病 PMR 随访均按医生安排记录；泼尼松起始 40–60 mg/d【待核】按医嘱阶梯减量，托珠单抗 162 mg 皮下【待核】以医嘱原文呈现。以上按受累器官与病情轻重排列，不代表任何一项适合你；选哪一个，需要问你的医生。

### 发展趋势

本台尚未采集 GCA 临床试验快照（检索词口径：giant cell arteritis / temporal arteritis / Horton disease / vasculitis / tocilizumab）；ClinicalTrials.gov 实测计数待 M4 真实快照回填【待核】。本台不做化验分级、不生成疾病活动度或预后评分。

## 关键功能（原型在建，截图待 GCA 版产出后补）

- 看板 · 两套合成档案：A 刚确诊记录少 / B 长期随访发作多；切换整页联动不串档。
- 化验 · 一图秀：ESR/CRP/血常规各自按全期归一化，末点标注、来源行同屏；跨方法不连线。
- 用药与剂量 · 阶梯表：泼尼松剂量段（mg/d + 起始日期）与托珠单抗等医嘱原文（162mg 皮下每周或隔周【待核】）留档。
- 发作与缓解 · 时间线：一次发作一条区间带；「近 90 天发作 N 次」读时算、不落库。
- 症状与视力预警：原文记录 + 当日就医提醒占位（仅记录不判读）。
- 影像与活检：颞动脉超声晕轮征所见、活检依据、CTA/MRA/PET-CT 复查与「距上次 N 天」。
- 临床试验线：建档→检索→匹配→呈现/收藏四段链路（口径见 `docs/CLINICAL-DATA.md` §六）。
- 复诊准备导出：私密三出口共用同一过滤函数。

## 怎么用

1. DSH Desktop 安装本包（装机验证未做；安装前可预览 `prototypes/` 下 HTML 原型——当前原型为家族底本移植态，GCA 化改造进行中）。
2. 顶栏「配置资料目录」选择本机目录（主目录/桌面/下载根/tmp 不作资料目录；M6 前须用户指定，见 `docs/DEV-REQUIREMENTS.md` §五）。
3. 「＋ 新建档案」建立自己的档案；演示档案标「[演示]」，只读可切换。
4. 顶栏「AI 对话」走宿主原生会话；页面内「和 AI 讨论」按钮把本页关键信息填进输入框草稿（只填不发）。

## 数据与口径

- 演示数据唯一源：`demo/` 构建脚本；界面全部标注「合成示例 / 仅演示 / 未连接宿主」。
- 真实库：SQLite（schema 冻结合同见 `schema/`）。
- 私密三出口（看板摘要/导出/AI 上下文）共用同一过滤函数；更正=新增版本，不覆盖。
- 临床试验快照：ClinicalTrials.gov query.cond=giant cell arteritis 联网实测 195 条（2026-11-14）；仓内快照未建立，通道失败如实 FAILED。
- 全站口径：「仅回顾，不解读」「解读归医生」「不同方法不合并」。
