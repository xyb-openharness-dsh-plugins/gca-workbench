# 项目规格 v0.1 · gca-workbench（巨细胞动脉炎 GCA）

版本 v0.1 · 2026-11-14 · 自动签认状态：夜班无人值守草案，晨审未追认；确认人/日期待补。不得把本模板当成已确认业务。

## 问题、用户与最小闭环

- 问题：巨细胞动脉炎（GCA）患者的炎症指标化验、影像与活检报告、激素剂量调整、视力预警发作、共病 PMR 随访记录散落在风湿科/眼科/神经科等多家医院，患者自己拼不出一份完整病程回顾。
- 用户：GCA 患者本人（主，50 岁以上发病人群为主），家属照护者（代记与陪同就诊，次）。
- 最小闭环：导入/录入化验与报告 → 核对入档 → 看板回顾炎症指标趋势、激素剂量阶梯与发作—缓解区间 → 导出复诊材料（私密过滤）。
- 输入：本机资料目录中的化验单/超声/CTA/MRA/PET-CT/活检报告 + 手工录入。动作：核对候选、新增发作/症状/用药/剂量段。输出：指标卡、发作时间线、剂量阶梯表、复诊导出。失败恢复：候选拒收零副作用、更正=新版本。成功标准：患者能在 5 分钟内回答「上次 ESR/CRP 多少、什么时候、哪家医院」。

## 设计者与研究/场景依据

按 DESIGN-PROMPT 与 DESIGNER-BRIEF 对齐角色、研究方法与取舍原则；用户需求证据与专业约束分开。证据/假设→需求→场景取舍→功能→验收逐级留痕，独立模型 review 写入 DESIGN-REVIEW.md。0 患者访谈（见 USER-RESEARCH.md），场景全为 L3 推断，不冒充引语。

## 方案与 ADR

比较 2–3 个真实候选方案的效率、运行条件与维护成本并记录选择；目标宿主能力表：能力/官方合同/本机核验/替代路径；不复用未经核验的版本号。

## 功能范围

一级页面：看板 / 化验 / 发作与缓解 / 影像与活检 / 症状与视力预警 / 用药与剂量 / 共病与筛查随访 / 报告 / 设置（详见 INTERACTION-DESIGN.md）。场景映射见 SCENARIOS.md（S1–S8 一期，S9–S11 暂缓）。稳定功能 ID 映射组件、API、测试；FEATURE-INVENTORY.csv 于 M2 建立并双向对账。

## 数据与 API

实体/关系/表、事实与候选、来源、时区与单位、迁移、读模型版本见 SCHEMA.md 与 API-CONTRACT.md。GCA 语义要点：ESR/CRP 按方法与机构可比组分列；泼尼松剂量以「mg/d + 起始日期」记为剂量段而非事件点；视力预警症状仅记录不判读。外部信息合同（来源/有效范围/冲突处理/刷新策略）沿用家族口径；获取成功不等于已核实。
